# NotebookLM Slide Editor

PDF/이미지 슬라이드의 글자를 지우고 바꿔 쓰는 로컬 편집기. 영역을 지정하면 Gemini가 글자를 읽고, 원본과 가장 비슷한 한글 글씨체를 찾아 적용한다.

## 실행

**필요:** Node.js, Gemini API 키

1. 패키지 설치: `npm install`
2. `.env.example` 을 `.env.local` 로 복사하고 `GEMINI_API_KEY` 에 키 넣기 — https://aistudio.google.com/apikey 에서 발급 (`.env.local` 은 git 에 올라가지 않음)
3. 실행: `npm run dev` → http://localhost:3000
   - Windows 에서는 `run.bat` 을 더블클릭해도 된다 (패키지가 없으면 설치하고, 브라우저를 자동으로 연다)
4. (선택) 탐색기 "연결 프로그램"에 등록: `launcher/install.bat` 실행 → 사진·PDF 를 오른쪽 클릭 → 연결 프로그램 → '슬라이드 편집기'
   - 편집기가 꺼져 있으면 켜고, 켜져 있으면 그 창에서 바로 연다. 해제는 `launcher/install.bat -Uninstall`

## 단축키

**화면**

| 조작 | 동작 |
| --- | --- |
| 드래그 / 가운데 버튼 드래그 / Space + 드래그 | 이미지 이동 |
| 휠 | 확대 / 축소 (마우스 위치 기준) |
| 마우스 4번(뒤로) 버튼 | 확대·이동한 화면을 처음 크기로 가운데에 되돌림 (전체화면은 유지) |
| 오른쪽 클릭 | 전체화면 켜기 / 끄기 |
| PageUp / PageDown | 이전 / 다음 슬라이드 |

**영역 선택과 텍스트 상자**

| 조작 | 동작 |
| --- | --- |
| Ctrl + 드래그 | 글자를 읽을 영역 선택 (모서리를 끌어 크기 조절) |
| Esc | 적용 전 선택 영역 취소 |
| 더블클릭 | 텍스트 상자 글자 편집 — Ctrl + Enter 완료, Esc 편집 취소 |
| 방향키 / Shift + 방향키 | 선택한 텍스트 상자 1px / 10px 이동 |
| Delete | 선택한 텍스트 상자 삭제 |
| Ctrl + C / Ctrl + V | 텍스트 상자 복사 / 붙여넣기 |
| Ctrl + Z | 실행 취소 |

**자르기 중**: 모서리 드래그 = 크기 조절, 안쪽 드래그 = 영역 옮기기, 바깥 드래그 = 이미지 이동

무료 등급은 하루 20회 제한이 있고, 분석 한 번에 2회(글자 인식 + 글씨체 비교)를 쓴다. 한도를 풀려면 API 키 프로젝트에 결제를 연결한다.

API 키가 브라우저 코드에 포함되므로 내 PC에서만 쓰고, 빌드 결과물(`dist`)을 인터넷에 올리지 말 것.
